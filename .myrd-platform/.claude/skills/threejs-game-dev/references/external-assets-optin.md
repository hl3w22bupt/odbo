# 外部生成 opt-in 通道与资产来源台账（external-assets-optin）

> 定位：程序化资产（`procedural-assets.md`）是**默认与主线**，红线与门禁不变；
> 本文件是 hero 资产的**唯一升级通道**（借鉴 threejs-game-skills 的凭据探测 + 优雅降级设计，
> 它证明「程序化为默认、外部生成为点睛」可以共存 —— 且同时满足包体与成本约束）。
> 侧邻关系：`style-card-library` 管「风格长什么样」，本文件管「外部来的资产怎么治理」。

## 1. 何时允许走外部生成（opt-in 边界）

| 资产 | 通道 |
|---|---|
| 场景物件、道具、地板/墙面贴图、UI、常规音效 | **只许程序化**（配方库覆盖，零例外） |
| **hero 资产**：主角、载具、Boss、宣传图/封面图、主题曲 | 允许 opt-in 外部生成 |

判断口令：**该资产是否出现在宣传物料或玩家注视中心**。是 → 可 opt-in；否 → 程序化。
系统性用外部生成替换程序化风格 = 违规，不做。

## 2. 凭据探测 → 优雅降级（先探测，后动手）

外部生成服务全部是付费 API（Tripo 文/图生 3D、Gemini 图像、ElevenLabs 音频类）。
**先探测凭据，再决定路线**；缺 key 不是错误，是回退信号：

```bash
# 零依赖探测（按需挑要用的服务；命中哪个走哪个，全空走程序化）
node -e 'for (const k of ["TRIPO_API_KEY","GEMINI_API_KEY","ELEVENLABS_API_KEY"]) console.log(k, process.env[k] ? "present" : "missing")'
```

- **有 key** → 走外部生成；提示词必须先引用风格卡（palette/线条/形状语言/禁忌），
  生成后对照风格卡做一致性检查（风格统一不因资产来源而豁免）。
- **缺 key** → **回退程序化并在交付说明明示**：「hero 资产为程序化兜底，未走外部生成
  （原因：缺 <KEY>）」。禁止静默降级 —— 让人分得清「点睛了」和「兜底了」。
- **绝不**把付费服务写成默认依赖：工程 package.json / 构建脚本不得依赖任何外部生成服务存在。

## 3. 内联与体积预算（单文件契约不豁免）

外部产物进入工程仍受 `tests/singlefile.contract.mjs` 零外链机判约束：

1. **构建后必须内联**：GLB/贴图/音频转 base64 data URI 或烘焙进程序化管线
   （如生成贴图 → 降采样 → `CanvasTexture` 等价重建），禁止运行时远程拉取。
2. **体积预算（建议值，超了先减面/压贴图，确需突破在交付说明标注）**：
   单件 hero 资产内联后 ≤ 2MB；全部外部资产合计 ≤ 产物体积的 50%。
   单文件产物膨胀到 MB 量级会吃掉「点开即玩」的加载优势 —— 这就是为什么只有 hero 值得付费。
3. 引入外部模型时优先减面 + 合并材质（drawCalls 与 triangles 会进 smoke 性能快照，
   画面/资产变更后重跑 `browser-smoke.mjs` 留证据）。

## 4. 许可红线

- 只允许 **「生成即授予商用权」** 的服务条款，或明确 CC0 / 已购商用授权的素材。
- 服务条款默认禁止转售/再分发的（如某些服务的输出仅限内部使用）不得用于可玩交付物。
- 记不清 = 不许用。许可字段是台账必填项，写「未知」的资产不许进交付。

## 5. 资产来源台账（必填，进工程根目录）

每个外部资产在 `<工程>/asset-ledger.md` 登记（对齐 threejs-game-skills 的 sourcing ledger
与策划案八段的资产治理段；CC0 素材库的同构台账见 godot-game-dev/assets/cc0/LICENSES.md）：

```markdown
# 资产来源台账

| 资产 | 用途 | 来源服务 + 提示词存档 | 许可 | 体积(原始→内联) | 替换成本(程序化兜底) | 引入日期 |
|---|---|---|---|---|---|---|
| hero-ship.glb | 主角载具 | Tripo #req123，提示词见 prompts/hero-ship.txt（引用风格卡 night-palette） | 服务条款：生成内容商用授权（存档 terms/） | 4.1MB → 1.8MB（减面 70%/贴图 1024） | 几何拼装版 ~2h，画质损失：曲面细节 | 2026-10-23 |
```

- **提示词必须存档**（prompts/ 下或台账内嵌）：复现生成、审计风格一致性、服务不可用时兜底。
- **替换成本列是台账的灵魂**：记录「退回程序化要多少工作量、损失什么」——
  它把「点睛」和「绑架」区分开：任何外部资产随时可退回程序化，才算 opt-in 而非 lock-in。
- 服务侧凭证（请求号/条款快照）随台账存档，平台 compliance 例行检查会抽查。

## 6. 与门禁的关系

外部资产**不豁免任何门禁**：preflight / run-all / browser-smoke（双视口 + 像素断言）
照常全跑；资产变更属于「画面/资产/shader 变更必跑 smoke」的触发条件，重跑后把新的
性能快照与截图一起归档。台账与 qa/smoke 证据共同构成资产变更的可核对记录。
