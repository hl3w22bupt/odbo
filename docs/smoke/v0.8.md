# 心伴 v0.8 冒烟步骤

命令：

```bash
npm run smoke
```

预期：45 / 45，exit 0。

## 兼容基线（01-38）

- 01-13：登录、会话、消息、SQLite 重启、令牌刷新。
- 14-22：记忆 / 情绪轨迹 / 情绪洞察读契约、空态与就绪态。
- 23-28：情绪修正 latest-wins、持久化、同交互标注、失败降级。
- 29-31：JSON 导出 schema、Content-Type、空库空结构。
- 32-38：JSON 导入恢复、往返一致、幂等、版本 / schema 拒收。
