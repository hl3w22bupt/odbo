# 心伴 v0.13 P0 · 数据导入/导出用户触达最小版 + v0.12 开放点定案

状态：FROZEN-SIGNED（2026-10-16 产品/架构契约冻结；代码评审通过即生效，执行期不扩需求）。

## 1. 范围与入口

1. 仅两处用户入口，零新建页面：
   - 设置页 = 既有 `HomeScreen` 的「数据与设置」页内卡片位；
   - 报告页 = 既有 `ChatScreen` 情绪报告/洞察信息区页内卡片位。
2. 两处复用同一个非路由卡片组件；报告页既有独立导入按钮并入卡片，避免第三入口。
3. 不改导航路由表、不新增 Screen、不改既有报告/洞察面板展示契约。

## 2. 导出契约

- 直连既有 v0.9 端点：`GET /api/v1/conversations/:id/mood-period-comparison/export.csv?periods=3`，Bearer 鉴权。
- Web 收到原始 CSV 后构造 `Blob(type='text/csv')`，创建临时 anchor 并 click 触发下载。
- 文件名：`心伴周期-<periodId>.csv`；`Content-Disposition` 的中文文件名必须追加 RFC 5987 `filename*=UTF-8''...`，既有 ASCII fallback 保留。
- 客户端不得改写 CSV 字节；无响应体或非 `text/csv` 按失败 toast，不触发下载。

## 3. 导入契约

- 继续复用 v0.12：`POST /api/v1/conversations/:id/mood-period-comparison/import.csv`；Web 文件选择后 `file.text()`，走既有 JSON `{ csv }` 便捷通道。
- 结果反馈必须展示成功 / 跳过 / 失败计数；有明细时渲染 `行号 + 原因`。
- 列表封顶 3 条；超出折叠为 `+N 行`。所有失败原因经 HTML 实体转义后作为纯文本渲染，禁止注入执行路径。
- **架构边界①**：客户端 1000 行计数只是体验提示，不是契约，也不阻断请求；服务端 `CSV_IMPORT_ROW_LIMIT=1000` 是唯一权威。双端判定不一致时，一律消费服务端响应。
- **架构边界②**：v0.12 响应已含 `failures` 明细，客户端纯消费；本轮服务端导入既有七字段语义零变更。仅在未知周期标识被排除时追加 `meta` / `warnings`，不修改既有字段，不改变计数不变量。

## 4. v0.12 遗留开放点定案：未知周期标识

- 聚合/洞察输入中未知（非真实日期或非东八区周一）周期标识不再转 404/500：跳过聚合写入/读侧参与，计入 `meta.skippedUnknownPeriodCount`。
- `warnings` 追加封闭标记 `UNKNOWN_PERIOD_SKIPPED`；只加不改，已知周期输出结构保持 v0.10/v0.11 语义。
- 纯未知极端输入返回 HTTP 200、合法空/降级结构；不新增错误码。
- 跨周期洞察新增 additive 查询 `period_ids`（逗号分隔，1-3 个）作为既有 `periods=N` 派生序列之外的显式测试/调试输入，用于表达混合已知/未知序列；未传时既有行为改为未知目标也 200 容错，已知目标零漂移。
- 聚合/洞察既有测试全集必须复跑，v0.10 空态契约零回归。

## 5. 硬验收

1. v0.9 导出文件原样反向喂导入：幂等跳过 = 记录总数、新增 = 0。
2. 混合已知/未知与纯未知用例：200 + 合法结构 + 跳过计数正确 + `UNKNOWN_PERIOD_SKIPPED`；纯未知保持空态。
3. 前端值级断言：导出端点/方法、Blob 下载、RFC 5987；导入端点与行号/原因真实渲染；仅按钮存在不算通过。
4. `<script>` 失败载荷渲染为 `&lt;script&gt;`，无脚本执行语义。
5. 客户端预检与服务端不一致双向用例：一律返回服务端响应。
6. 若走「只加不改」：导入既有字段逐项不变契约回归必须常驻。
7. 回环、容错测试进 `npm test` CI 常驻；v0.13 新增用户链路进 `npm run smoke`。

## 6. 停车场

通用 ETL、Excel/PDF、进度条、多文件批量、服务端签名下载 URL、设置页会话选择器均不入本轮。
